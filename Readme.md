# Оптическое умножение матриц — POMMM и Lumai-архитектура

Библиотека реализует два физически различных подхода к оптическому умножению матриц:

- **OpticalMul** — 4f система с преобразованием Фурье (по статье Zhang et al., Nature Photonics 2025)
- **LumaiMul** — архитектура в стиле Lumai: fan-out линза + дисплей весов + суммирующая линза

---

## OpticalMul — 4f система (POMMM)

### Целевое оборудование

| Компонент | Модель | Параметры |
|-----------|--------|-----------|
| Лазер | Одночастотный, 532 нм | Когерентный, непрерывный |
| ASLM1, ASLM2 | Upolabs HDSLM80R-A | 1200×1920 пкс, шаг 8 мкм, 8-bit, 60 Hz |
| PSLM | Upolabs HDSLM80R-P Pro | 1200×1920 пкс, шаг 8 мкм, 10-bit, 60 Hz |
| Линзы | Thorlabs ACT508-200-A | f = 200 мм, ахроматические |
| Камера | Hamamatsu ORCA-Quest C15550-20UP | qCMOS, 16-bit |

**Физический предел:** матрицы до ~50×50 при rep=100 (NRMSE < 0.1).

### Подготовка

```python
config = source.Config(
    right_matrix_count_columns = 16,
    right_matrix_count_rows    = 16,
    right_matrix_width         = 3.6e-6 * 16,
    right_matrix_height        = 3.6e-6 * 16,
    min_height_gap             = 3.6e-6,
    right_matrix_split_x       = 2,
    right_matrix_split_y       = 2,
    left_matrix_split_x        = 2,
    left_matrix_split_y        = 2,
    result_matrix_split        = 2,
    distance                   = 0.01
)

mul = source.OpticalMul(config)
```

### Использование

```python
# Вещественные матрицы
A = torch.rand((1, 1, 16, 16))
B = torch.rand((1, 1, 16, 16))
C = mul(A, B)  # (1, 1, 16, 16)

# Комплексные матрицы
A_c = torch.rand((1, 1, 16, 16)) + 1j * torch.rand((1, 1, 16, 16))
B_c = torch.rand((1, 1, 16, 16)) + 1j * torch.rand((1, 1, 16, 16))
C_c = mul(A_c, B_c)  # (1, 1, 16, 16)
```

## LumaiMul — архитектура Lumai

Реализует физический pipeline некогерентного оптического умножителя:

```
[M VCSEL лазеров] → [fan-out линза] → [дисплей весов W[M,N]] → [суммирующая линза] → [N детекторов]
```

Каждый детектор j вычисляет: `y[j] = Σᵢ |x[i] · W[i,j]|²`

Ключевые отличия от OpticalMul:

| | OpticalMul (4f) | LumaiMul |
|---|---|---|
| Источник | Когерентный лазер 532 нм | VCSEL матрица 850 нм |
| Суммирование | Обратный FFT | Физическая линза |
| Комплексные данные | ✅ полная поддержка | ⚠️ только амплитуда |
| Масштаб | ~50×50 | до 1024×2048 |
| Точность по фазе | ✅ | ❌ (некогерентный свет) |

### Целевое оборудование

| Компонент | Модель | Параметры |
|-----------|--------|-----------|
| Лазерная матрица | VCSEL массив (н-р Lumentum) | 1024 источника, 850 нм, шаг 20 мкм |
| Fan-out линза | Дифракционная DOE или рассеивающая | Покрывает всю апертуру дисплея |
| Дисплей весов | **HOLOEYE GAEA-2.1** | 4160×2464 пкс, шаг 3.74 мкм, 8-bit |
| Суммирующая линза | Ахроматическая, f = 10–50 мм | Фокусирует столбцы на детекторы |
| Детектор | Фотодиодная матрица (CMOS) | 2048 детекторов, быстрый |

**Почему HOLOEYE GAEA-2.1?** Это SLM с наибольшим разрешением на рынке (10 мегапикселей, шаг 3.74 мкм). При использовании в режиме амплитудной модуляции через скрещенные поляризаторы позволяет обрабатывать матрицы до 416×246 за один оптический такт (при rep=10), что даёт умножение 512×512 за **12 выстрелов** (0.2 сек при 60 Hz).

### Подготовка

```python
lumai_config = source.LumaiOpticConfig(
    n_lasers         = 1024,    # число VCSEL лазеров = M
    n_outputs        = 2048,    # число детекторов = N
    laser_pitch      = 20e-6,   # шаг VCSEL матрицы [м]
    detector_pitch   = 20e-6,   # шаг детектора [м]
    display_pitch    = 3.74e-6, # шаг пикселя GAEA-2.1 [м]
    fanout_distance  = 0.05,    # расстояние лазер → дисплей [м]
    summing_distance = 0.05,    # расстояние дисплей → детектор [м]
    wavelength       = 850e-9,  # длина волны VCSEL [м]
    display_bits     = 8,       # битность дисплея
    incoherent       = True     # некогерентный свет (физика Lumai)
)

mul = source.LumaiMul(lumai_config)
```

### Использование

```python
# Базовое умножение: A[B,C,H,M] @ W[B,C,M,N] → C[B,C,H,N]
A = torch.rand((1, 1, 64, 1024))
W = torch.rand((1, 1, 1024, 2048))
C = mul(A, W)  # (1, 1, 64, 2048)
```

### Блочное умножение для больших матриц

Для матриц с K > n_lasers используйте `LumaiMulBlocked` — автоматически разбивает на блоки и суммирует результаты (некогерентное сложение интенсивностей):

```python
# Умножение матриц 512×512 при n_lasers=1024
lumai_config = source.LumaiOpticConfig(
    n_lasers=1024, n_outputs=2048, ...
)
blocked_mul = source.LumaiMulBlocked(lumai_config, block_size=1024)

A = torch.rand((1, 1, 512, 512))
W = torch.rand((1, 1, 512, 512))
C = blocked_mul(A, W)  # (1, 1, 512, 512)

# Число оптических тактов: ceil(512/1024) × ceil(512/1024) × ceil(512/1024) = 1
# При 60 Hz GAEA-2.1: ~16.7 мс на операцию
```

## Сравнение архитектур с GPU

| | OpticalMul | LumaiMul | H100 GPU |
|---|---|---|---|
| 512×512 | ~22 сек (Upolabs) | 0.2 сек (GAEA-2.1) | **0.001 мс** |
| Энергоэфф. | 2.62 GOP/J | ~50–100 GOP/J* | ~300–1000 GOP/J |
| Масштаб матриц | ~50×50 | до 416×246 за такт | без ограничений |
| Комплексные числа | ✅ | ❌ (только \|A\|) | ✅ |

*оценка для специализированного железа

**Вывод:** оптические умножители пока уступают GPU по скорости и энергоэффективности на отдельных операциях. Реальное преимущество оптики — в edge-устройствах без GPU и в будущих интегральных фотонных чипах.
