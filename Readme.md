# Оптическая операция умножения матрицы на вектора
## Подготовка
1. Создаётся объект конфигурации оптической установки `Config`, содержащий все параметры модели системы оптического матричного умножения.
Особое внимание уделяется размеру вычислительной области `array_size`, размеру вектора `vector_size` внутри оптической установки, а также коэффициенту масштабирования `scale_by_x`: параметры позволяют настроить желаемую точности результата и скорость вычисления.
3. Задаётся оператор распространения световых волн в свободном пространстве (в данном случае задан `Propagator_sinc_operator` в виду его наибольшей точности), и объект пропагатора `Propagator`.
4. Создаётся объект системы оптического умножения матрицы на вектор `OpticalMul`.
```python
config = source.Config(scale_by_x = 2,
                       vector_size = 16)

propagator_operator = propagator.Propagator_sinc_operator()
prop = propagator.Propagator(operator = propagator_operator,
                  config = config)
mul = source.OpticalMul(prop, config)
```
## Принип использования
Созданному объекту системы подаётся на вход два тензора: тензор левой матрицы (B, C, H, W) и тензор правой вектора (B, C, W, K) на выходе получается тензор размерностью (B, C, H, K).
```python
matrix = torch.rand((1, 1, 128, 256)) > 0.5
vector = torch.rand((1, 1, 256, 64)) > 0.5
mul(matrix, vector).shape
# torch.Size([1, 1, 128, 64])
```

# Ветка partial-coherence: некогерентная схема поверх когерентного движка

Назначение: количественно ответить на возражение оптиков («некогерентный
источник в текущем исполнении всё ломает» / «нужна задержка считывания,
величину не знаем») и дать вход в выбор архитектуры прототипа — до закупки.

## Физическая модель

Каждый излучатель сам с собой когерентен, поэтому его поле на детекторе
считается существующими пропагаторами репо без изменений. Некогерентность
входит только в суммирование на детекторе:

    I(y) = Σ_i |E_i(y)|²  +  Σ_{i≠j} γ_ij · Re[E_i E_j* e^{iφ_ij}]

Вся схема сведена к передаточной матрице `T[out, emitter]`, извлекаемой одним
батчированным forward-проходом (identity по оси H) через немодифицированный
`OpticalMul`. Дальше:

- когерентный режим:   y = |T @ x|            (текущий сим, кросс-чек);
- некогерентный режим: I = |T|² @ I_in        (обычный вещественный матмул);
- частичный режим:     произвольная γ-матрица (диагональ 1);
- режим биений:        честная временная симуляция с расстройками Δν_ij,
  фазовой диффузией (linewidth) и прямоугольным окном интегрирования АЦП.

## Файлы

- `pc_engine.py` — TransferMatrix, PartialCoherentMul, VCSELArraySpec,

- `test_partial_coherence.py` — исполняемая спецификация (T1–T6).

| T2 некогерентный == поэлементная сумма интенсивностей | ε ≈ 8e-8 |
| T3 пределы γ=1 / γ=0 | ε ≈ 1e-7 |
| T4 закон усреднения ε(M) | наклон −0.49 (теория −0.5) |
| T5 биения при Δν=2.5 ГГц спейсинге, 4 окна АЦП | ε ≈ 1.3% |

## Следствия для решений

1. «Задержка считывания» — не неизвестная, а формула: t = M · τ_decorr,
   M ≈ (γ/ε)², калибруется `epsilon_vs_averaging` (T4). Для стенда
   1 лазер + DMD (γ=1) при ε=1% нужно M ≈ 10⁴ реализаций.
2. Для настоящей линейки задержка снимается спектральным спейсингом:
   правило Δν_min ≥ f_АЦП + 2·f_mod (= 2.5 ГГц при f_АЦП=500 МГц,
   f_mod=1 ГГц). На 850 нм это ~6 пм — совместимо со слайдом «одна λ»;
   T5 подтверждает: ε ≈ 1% уже на 4 окнах АЦП.
3. Требование в спецификацию закупки — не «одинаковые лазеры», а
   гарантированный минимальный разбег частот + контроль температурного
   дрейфа (пары не должны съезжаться в полосу тракта).
4. Чувствительность |T|² к λ (T6) мала на этой геометрии: нм-спред линейки
   даёт ~0.2% — спред по λ не проблема для точности ядра, проблема только
   попарные Δν в полосе детектора.

## Открытые вопросы к оптикам

1. «Изменения при вводе данных» — это временнóе мультиплексирование,
   вращающийся диффузор или что-то третье? (Для обоих вариантов сим уже
   даёт таблицу «задержка ↔ точность».)
2. Есть ли данные по спектрам кандидатных VCSEL-массивов: попарные
   расстройки, ширина линии, температурный дрейф?
3. Верна ли геометрия 4×d (вход → линза → SLM → линза → выход) для
   некогерентного варианта, или fan-out/fan-in планируется другой оптикой
   (коллиматор + цилиндрические линзы, как на слайде)?
